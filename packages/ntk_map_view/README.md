# ntk_map_view

Локальный пакет карты для `azs_app`. Виджет открывает MapLibre GL JS в
`WebView` и принимает стиль MapLibre (`styleUrl`), в том числе
`https://storage.yandexcloud.net/eg-small-backet/map/lightmap.json`.

Пакет лежит в репозитории (`packages/ntk_map_view`) и подключается path-
зависимостью внутри проекта, без внешних каталогов.
