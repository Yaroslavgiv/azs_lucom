# Пилот и промышленный запуск

## Окружения

Демо-проект `my-home-chat-915a3` не использовать как промышленный. Для пилота:

1. Создать отдельный Firebase-проект.
2. Включить Email/Password.
3. Развернуть `firestore.rules`, `storage.rules` и `functions/`.
4. Создать первого администратора в Authentication и документ `users/{uid}` с `role: admin`.
5. Заменить клиентский конфиг (`lib/firebase_options.dart`, `google-services.json`).

## Критерии приёмки v1

- Заявка и отчёт ТО сохраняются на объекте без сети и уходят в очередь.
- Руководитель назначает исполнителя и срок.
- После приёмки ТО статус станции на карте становится зелёным.
- Добавление АЗС/оборудования сохраняет автора.
- Строки web-отчёта совпадают с выгрузкой XLSX.
- Чужие данные закрыты правилами; повторная отправка не создаёт дубли очереди.
