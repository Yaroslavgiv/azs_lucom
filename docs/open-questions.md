# Вопросы, которые остаются на заказчике

Код версии 1.3 опирается на допущения из [technical-design.md](technical-design.md).

- Месяц обслуживания считается в `Europe/Moscow` (UTC+3, без летнего времени), пока заказчик не задаст другой пояс.
- Длительности договорных заявок не выдуманы: без строки в `contract_rules` срок пуст.
- Предупреждение о приближении срока отправляется за 24 часа, если срок задан правилом. Окно можно заменить, когда заказчик его согласует.
- Перевод станции в другой отдел или управление блокируется, пока не решена судьба открытых заявок.
- Внешний источник заявок подключается через `RequestSource`, когда появится контракт.
- MFA, политика паролей, SLA, RPO/RTO и состав пилотной группы задаёт заказчик.
- Учётная запись Apple Developer и владение ей — обязанность заказчика.
- Фактическая миграция с Firebase не входит в эту версию; готов только порядок из [firebase-migration.md](firebase-migration.md).
