# Новая фича

- Feature-first: `lib/features/<name>/`
- Riverpod + repositories, без raw SQL в UI

- Подключи к MainShell или push-навигации

Уточни название фичи и нужна ли вкладка в bottom nav, если пользователь не сказал.
