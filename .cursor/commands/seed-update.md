# Обновить seed-данные

Следуй skill `.cursor/skills/seed-pipeline/SKILL.md`.

1. Определи какой asset меняется
2. Обнови JSON и/или скрипт в `scripts/`
3. **Bump** `_seedVersion` / `_dataVersion` в соответствующем seed-сервисе
4. Проверь `pubspec.yaml` assets
5. Кратко опиши, что изменится на уже установленных устройствах после bump
